# Open Finance

Open Finance é um sistema regulado pelo Banco Central que permite o compartilhamento de dados financeiros de uma pessoa entre diferentes instituições, mediante autorização expressa do próprio cliente.

## Como funciona

Em vez de cada banco ou corretora ter acesso apenas às informações da conta aberta ali, o Open Finance permite que o cliente autorize o compartilhamento de dados (como histórico de transações, investimentos e crédito) entre instituições diferentes, de forma segura e padronizada.

## Para que serve

- **Visão unificada**: o investidor pode ver todos os seus investimentos, de bancos e corretoras diferentes, em um único lugar.
- **Ofertas personalizadas**: instituições podem usar o histórico financeiro (com autorização) para oferecer produtos mais adequados ao perfil do cliente, como crédito com taxas melhores.
- **Portabilidade facilitada**: migrar de instituição financeira tende a ficar mais simples, já que o histórico pode ser compartilhado com o novo prestador de serviço.

## Segurança e controle do usuário

O compartilhamento de dados só ocorre com autorização explícita do cliente, que pode revogar o acesso a qualquer momento. As instituições participantes precisam seguir padrões de segurança definidos pelo Banco Central.
